# Skills grid logos

These local SVGs are inlined by `SkillsGrid.astro`; they require no remote requests.
The marks use the portfolio's dark ink color in both themes. Geometry is retained,
and colored fills are adapted to `currentColor` where needed. Icons are decorative;
the tool names remain visible and available to screen readers.
